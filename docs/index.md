# DIVA - Pet Guardian

DIVA is a Home Assistant custom integration for pet care tracking.
It models the installation as one DIVA hub with multiple pets and publishes entities,
runtime events, anomalies, recommendations, and per-pet timeline calendars.

## Highlights

- async-first coordinator runtime
- multi-pet hub model
- structured routine planner and exceptions
- nutrition, medical, mobility, behavior, and operations domains
- external calendar sync and custom editor panel
- JSON runtime storage in `/config/diva_runtime.json`
